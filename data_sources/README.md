# Data sources

The completed public experiment uses a fixed MSR-VTT feature mirror with ImageBind visual features and captions. The source revision, checksums, and limitations are recorded in `docs/data_search.md` and `data/prepared/`.

The original paper's Flickr/YouTube source inputs and Kodak/CCV/HMDB51 evaluation inputs are not available in the required four-MAT form. The repository therefore reports controlled method validation on public substitute data.
