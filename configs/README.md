# Configuration index

- `core.json`: five-seed core MIL/PI/DA protocol used by the final evidence.
- `baselines.json`: SA, TCA, KCCA, and SVM-2K extension.
- `literature.json`: KMM+SVM, STM, RT, DASVM, and uniform-cost SVM batch.
- `msrvtt.json`: compatibility runner for the original four-MAT/public-cache interface.
- `concept_events.json`, `concept_representations.json`, `full_adaptation.json`, and `full_adaptation_parallel.json`: optional exploratory branches.
- `paper_action.json` and `paper_event.json`: paper-scale inventories, not claims of completed original-data evaluation.
