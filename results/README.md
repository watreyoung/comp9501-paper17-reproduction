# Results

The result files in this directory are saved outputs from the completed public-data experiments, not examples. `final_report.md` reproduces the tables used in the course presentation from the machine-readable summaries.

- [`core/`](core/): MIL, PI, DA, full/shuffled controls, and KMM comparisons.
- [`baselines/`](baselines/): SA, TCA, KCCA, and SVM-2K.
- [`literature/`](literature/): KMM+SVM, STM, RT, DASVM, and uniform-cost SVM.
- [`summary.json`](summary.json): combined comparison and audit summary.

Raw prediction arrays, per-fit logs, plots, and feature caches are generated artifacts and are not included in the source repository.
