# Representative baseline extension

This batch uses the core public protocol and evaluates SA, TCA, KCCA, and SVM-2K heads. It contains 576 validation fits and 2,880 test fits, all independently audited. The comparison is representative rather than a completion of every original-paper baseline.

The report should be read together with `configs/baselines.json` and the core report; different training-cost conventions and label spaces are kept explicit.
