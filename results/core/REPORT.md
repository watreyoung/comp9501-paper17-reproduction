# Core public-data experiment

The core batch evaluates SVM/pSVM+, sMIL, mi-SVM, and MIL-CPB with PI, DA, full/shuffled controls, and KMM under the shared five-seed MSR-VTT substitute protocol. It contains 9,600 test fits and 1,056 validation candidates; 20 failed validation candidates remain recorded and are excluded from selection.

At 20% contamination in the full setting, the reported five-seed mAP values include sMIL-PI 44.63, mi-SVM-PI 44.36, mi-SVM-PI-DA 39.10, MIL-CPB-PI 28.72, and MIL-CPB-PI-DA 39.28. These are descriptive substitute-data results, not original-paper scores.
