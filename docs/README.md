# Documentation

This directory contains experiment protocols, implementation notes, and data provenance.

- `core_protocol.md`: main five-seed MIL/PI/DA experiment.
- `baseline_protocol.md`: representative SA/TCA/KCCA/SVM-2K baselines.
- `literature_protocol.md`: KMM+SVM, STM, RT, and DASVM batch.
- `data_search.md`: public-data source and limitations.
- `implementation_changes.md`: numerical and conversion checks.
- `concept_events_protocol.md`, `concept_representations_protocol.md`, and `full_adaptation*.md`: optional exploratory branches.

The final result summary is in `results/final_report.md`.
