# Baseline extension protocol

The extension uses the same public cache, domains, bags, contamination levels, seeds, and validation policy as the core run. It evaluates SA, TCA, KCCA, SVM-2K, and related classifier heads with pre-fixed dimensions and a validation-selected regularization scale.

The extension is a representative baseline comparison, not a claim that every baseline in the paper has been completed. See `results/baselines/REPORT.md`.
